Using a key

An API key lets a script or service call the Amelu API as you, with the same permissions your account has. Send it as a bearer token:

Authorization: Bearer amelu_live_...

Treat it like a password

  • Anything holding a key can manage your domains and mailboxes.
  • A key can't change your account or create other keys. That still needs you signed in.
