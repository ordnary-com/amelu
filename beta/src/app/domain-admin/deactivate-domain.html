Deactivate or delete?

Deactivating only pauses mail. To permanently erase this domain's data instead, for example to fulfil a data subject's erasure request under the GDPR, use Delete domain.

While it's deactivated

  • Incoming mail is rejected, so senders get a bounce.
  • Mailboxes can't send mail.
  • All mailboxes, messages and settings are kept.

After reactivating

The domain goes back to DNS pending until its records are checked again. Check the DNS configuration if it doesn't turn active on its own.
