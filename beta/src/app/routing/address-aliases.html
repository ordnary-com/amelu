How aliases work

  • Mail to the alias lands in the destination mailbox, as if it was sent there directly.
  • Each alias delivers to exactly one mailbox on this domain. A mailbox can have many aliases.
  • An alias can share its address with a mailbox. Enter only the part before the @; aliasing to other domains isn't possible.

Bulk changes

Export gives a CSV with one alias and its destination per row. Import takes the same format, so you can edit an export and load it back.
