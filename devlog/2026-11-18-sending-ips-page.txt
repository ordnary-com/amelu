Sending IPs page reworked with a filter sidebar
2026-11-18

The 2.0 dashboard's /network page was a flat list of the eleven outN
addresses. It now has a left sidebar with a search field (hostname or IP),
a pool filter with counts (Established senders, New domains, Amelu system
mail, Standby) taken from GROUPS and SPARES in ops/marduk/amelu-ip-pools.py,
and a short explanation of the selected pool. The
results are a table with hostname, address (copy button), pool and status
(Sending or Not sending yet), with an empty state when nothing matches. "Copy all IPs" copies the
filtered list. Only beta/src/app/network-page changed.
Later the same day the page also lists our own block: up to 64 addresses,
89.106.70.10-73 as out-10.mta0.amelu.org to out-73.mta0.amelu.org (cluster name
per /24, last octet as host), in a Warming up pool marked
Not sending yet so customers can allowlist them early (their DNS and
reverse DNS still have to be created). A Subnet filter (All, 51.89.0.0/16
current addresses, 89.106.70.0/24 own network) sits above the pool filter,
and the pool counts follow the selected subnet.
Made more technical: a Subnet column with CIDR and origin ASN per address
(51.89.0.0/16 AS16276, 89.106.70.0/24 AS218905, checked with
whois.cymru.com). The own block is not in _spf.amelu.org yet; it gets added
before those addresses send.
Pool filter reworked into "Used for": public labels (Customer mail, New
domains, Amelu notifications, Reserve, Warming up) with the description as
a tooltip, counts that follow the subnet filter, and
options without addresses in the selected subnet hidden. The table column
uses the same labels and tooltips.
